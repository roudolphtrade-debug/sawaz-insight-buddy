# Retrouver le compte Sawaz Pilot (lecture seule)

Constat : la base actuellement reliée au projet ne contient aucun compte (0 utilisateur, 0 rôle).

## Étapes
1. Vous reliez la base Results Studio : Project Settings → Connectors → Supabase → Connect/Reconnect.
2. Je relance la même vérification en lecture seule et je vous donne, pour chaque compte : e-mail, rôle (owner/analyst/viewer), confirmé ou non, date de création.
3. J'indique le compte owner seulement s'il est identifiable sans ambiguïté.

## Garanties
Aucune création, modification, réinitialisation, aucun changement de rôle, de règle d'accès ou de configuration, aucune publication. Aucun mot de passe, token ou hash affiché.
